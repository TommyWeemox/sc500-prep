## 4.1 Defender for Cloud

| Sujet | À retenir |
| --- | --- |
| Foundational CSPM (gratuit) | Inventaire, recommandations, **secure score**, **MCSB**, export, workflow automation |
| Defender CSPM | **Chemins d'attaque**, **cloud security explorer**, **gouvernance**, sans agent, DSPM, AI-SPM, **EASM inclus**, conformité ajoutée |
| Conformité | MCSB par défaut ; autres standards = **plan payant** ; voir = **Reader** (pas Security Reader) ; ~**12 h** ; attestation manuelle |
| AWS | **Compte de gestion** = membres actuels et futurs ; CloudFormation ; fédération ; Arc + SSM pour Servers |
| GCP | Projet ou organisation ; script **gcloud** ; workload identity federation |
| Intervalle | **4, 6, 12 ou 24 h** |
| MDVM | Sans agent : **P2** ou **Defender CSPM** ; avec agent : P1/P2 ; activé par défaut |
| EASM | Graines (domaines, IP, hôtes, ASN, Whois, e-mails) ; **Approved Inventory** analysé chaque jour ; **Candidate** à qualifier ; essai 30 j |

## 4.2 Sentinel

| Sujet | À retenir |
| --- | --- |
| Portail | Azure portal **fini après le 31/03/2027** ; portail Defender, un workspace principal par tenant |
| Workspace | **Un seul** par défaut ; pas sur workspace Defender for Cloud ; **non déplaçable** ; 90 j de rétention inclus |
| Rôles | Reader < **Responder** (incidents) < **Contributor** (contenu, content hub) ; **Playbook Operator** ; Automation Contributor = service ; RG |
| Content hub | Solutions (cycle de vie), standalone ; Microsoft, partenaire, communauté |
| Azure Activity | Connecteur par **Azure Policy** |
| Syslog/CEF | AMA sur forwarder Linux (**Arc** si hors Azure) ; **514** ; tables Syslog / **CommonSecurityLog** ; même facility = doublons |
| Windows | All / Common / Minimal / XPath **1.0** ; WEF : AMA sur WEC, table **WindowsEvent** (pas SecurityEvent) |
| Tables perso | **_CL**, TimeGenerated, DCR, **Logs Ingestion API** (HTTP Data Collector fini le 14/09/2026) |
| Automatisation | Incident créé / mis à jour, alerte créée ; ordre ; **expiration** ; playbook = droits Sentinel sur le **RG du playbook** (Owner pour accorder) |
| Rétention | Analytique **730 j** max, totale **12 ans** ; data lake (Parquet, miroir, KQL jobs, notebooks) |
| Audit Purview | Audit Logs / View-Only ; **180 j** / 1 an E5 ; XDR : **CloudAppEvents** via Defender for Cloud Apps |

## 4.3 Security Copilot

| Sujet | À retenir |
| --- | --- |
| Workspace | Sessions, **SCU**, rôles, plugins isolés ; **stockage immuable** (ANZ, EU, CH, UK, US) ; évaluation même région ou anywhere |
| Capacité | PAYG : provisionnées + **overage** ; E5 : **400 SCU/mois pour 1 000 licences** |
| Agents intégrés | Routage par produit (tenant) ; défaut = **plus ancien** workspace |
| Rôles | **Copilot owner / contributor** (pas Entra) ; owners hérités : Global Admin, Security Admin... ; **on-behalf-of** |
| Plugins | Préinstallés : tous ou owners only (affecte l'intégré) ; perso : owners par défaut, YAML/JSON |
| Agents | Trigger, permissions, **identity** (Agent ID recommandé), plugins ; partenaire = approbation **Global Admin** |
| Security Store | Agents, SaaS, connecteurs, services ; facturation Marketplace |

## Pièges fréquents du domaine

- Donner Security Reader à un auditeur de conformité (il faut Reader).
- Chercher les événements WEF dans SecurityEvent.
- Demander 7 ans de rétention **analytique**.
- Oublier les droits de Sentinel sur le groupe de ressources du playbook.
- Laisser des actifs EASM en Candidate.
- Croire que Copilot contributor ouvre les données Sentinel.
- Vouloir changer l'emplacement de stockage d'un workspace Copilot après création.
