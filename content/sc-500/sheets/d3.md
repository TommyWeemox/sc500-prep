## 3.1 Sécurité de l'IA

| Sujet | À retenir |
| --- | --- |
| Surexposition SharePoint | Rapports **DAG** (snapshot, activité 28 j) ; remédiation **Restricted access control**, **Site access review**. RCD masque à Copilot sans retirer de droits |
| DSPM for AI | Prérequis **Audit** ; évaluation hebdo des **100** sites les plus utilisés ; DLP par étiquette pour Copilot |
| Agents en temps réel (Defender) | Règle **Default** = audit ; règles personnalisées = **blocage** ; **BehaviorInfo** |
| Accès conditionnel agents | OBO → cibler **utilisateurs** ; app seule → **identité d'agent / blueprint** ; agent-user → son compte. Licence **M365 E7** ou **Agent 365** + P1/E3. Pas avec security defaults ni clés d'API |
| Gouvernance agents | **Sponsor** (métier) vs propriétaire ; access packages avec expiration ; actions M365 admin : **AI Administrator** |
| AI Gateway | APIM v2 (même tenant/abonnement) ; limites **par projet** ; **429** TPM, **403** quota |
| Defender for AI Services | Texte seulement ; Prompt Shields ; essai **30 j / 75 Md** jetons ; alertes dans Defender XDR |
| Guardrails Foundry | user input, **tool call / tool response** (agents), output ; défaut **Microsoft.DefaultV2** ; guardrail agent **remplace** celui du modèle |
| Tableau Data and AI security | Defender CSPM + Storage + Databases + AI workloads |

## 3.2 Serveurs et VM

| Sujet | À retenir |
| --- | --- |
| Chiffrement | SSE toujours ; **encryption at host** = + temp disk, caches ; **ADE retiré le 15/09/2028** |
| Bastion | **AzureBastionSubnet /26** ; IP Standard statique ; enregistrement de session = **Premium** |
| JIT | **Defender for Servers P2** ; NSG + Azure Firewall **règles classiques** (pas Firewall Manager) ; connexions établies non coupées |
| Arc Tier 0 | **Abonnement dédié** ; `azcmagent config` : connexions entrantes off, allowlist d'extensions |
| Defender for Servers | P1 : ressource ou abonnement ; **P2 : abonnement seulement** ; MDE auto ; MDVM par défaut |
| Sans agent | Instantanés de disques : vulnérabilités, secrets, malware (P2). Defender CSPM ou P2. Azure, AWS, GCP |
| Trusted Launch | Secure Boot, vTPM, **Guest Attestation** ; Gen2 ; défaut des nouvelles VM |
| Machine Configuration | **Audit**, **ApplyAndMonitor**, **ApplyAndAutocorrect** ; extension + identité managée ; 50 affectations |

## 3.3 Plateforme applicative

| Sujet | À retenir |
| --- | --- |
| Defender for Containers | Posture, vulnérabilités, runtime (dérive binaire), **gated deployment**, capteurs ; AKS, EKS, GKE, Arc |
| AKS | **Cluster User Role** pour la kubeconfig ; Azure RBAC pour Kubernetes au namespace ; API : IP autorisées ou cluster privé |
| ACR | Admin **désactivé par défaut**, compte unique sans RBAC ; `az acr login` = jeton **3 h** ; AcrPull par identité managée |
| Container Apps | **Workload profiles** (/27, UDR, NAT) vs consumption only (/23, pas d'UDR) ; accessibilité **Internal** |
| Functions | Clés ≠ authentification ; **Easy Auth**, APIM, réseau, isolation |
| Logic Apps | Déclencheur Request : régénérer SAS, **OAuth Entra** (iss, aud), IP autorisées ; **secure inputs/outputs** |
| App Service | **HTTPS only non par défaut** ; TLS 1.2 ; FTP/basic auth off ; identité managée ; références Key Vault |
| WAF | Front Door **Premium** = DRS et Bot Manager ; **Standard = règles perso seulement** ; custom avant managed ; Detection puis Prevention |
| APIM | Entrée **validate-jwt / validate-azure-ad-token** ; backend **authentication-managed-identity** |

## Pièges fréquents du domaine

- Cibler l'identité d'un agent quand il agit au nom de l'utilisateur (OBO).
- Croire que Restricted Content Discovery retire des permissions.
- Penser que les guardrails du modèle et de l'agent se cumulent.
- Activer Defender for Servers P2 « par VM ».
- Activer JIT derrière un Azure Firewall géré par Firewall Manager.
- Choisir Azure Disk Encryption pour une nouvelle VM.
- Garder l'utilisateur admin ACR « pour le pipeline ».
- Chercher le Default Rule Set sur Front Door Standard.
